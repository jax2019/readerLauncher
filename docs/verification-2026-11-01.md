# Neo 3 Ultra 实机验收记录

日期：2026-11-01。设备：掌阅 Neo 3 Ultra / RM06L-CKDW，Android 14。构建版本：0.1.0，使用官方 Android SDK 工具链生成并校验 APK 签名。

## 桌面与入口

默认 HOME 已改为 `com.ireaderlauncher.app/.MainActivity`，原厂桌面仍可通过 `com.zhangyue.iReader.Eink/.home.ActivityLauncher` 显式打开。

以下入口均通过实际 UI 点击核验前台 Activity：

- 主页“官方桌面”进入原厂桌面，按 Home 返回阅桌面。
- 微信读书主卡片打开墨水屏版微信读书。
- 设置中的开发者选项、阅读灯、应用显示与刷新均成功打开对应页面。
- 省电助手可读取真实状态，充电时系统省电模式开关显示不可用。

## 控制与恢复

实机 Instrumentation 结果为 PASS，覆盖：默认桌面、关键入口解析、13 项省电状态、非法参数拒绝、轻度 Doze 切换、可选应用停用、应用原始启用状态精确恢复、日志录制与自启开关相互独立、推荐设置及完整恢复。

验证过程中发现厂商启停日志录制会连带改变自启配置。已修正：执行前完整备份相关原值，启停录制后恢复自启开关的独立状态。实际恢复检查确认可回到日志录制开启、自启开启、轻度 Doze 关闭的初始配置。之后重新应用了推荐配置。

独立 UID 的测试应用调用省电组件，被拒绝并记录 `PASS: unauthorized caller rejected`。任意命令片段及未列入允许范围的系统包操作也被拒绝。

## 应用优化语义更新

“可选应用”分组已改为“应用优化”。开启开关显示“已优化”，对应系统停用（冻结）；关闭显示“未优化”，对应重新启用。界面说明了冻结会阻止应用正常打开与自启动、重启后保持，且保留数据，并分别提示 AI、智能助手、市场、播放器、朗读与词典受影响的功能。

应用状态从系统实际启用状态推导，保留了旧接口 `enabled` 的含义，增加独立的 `optimized` 状态；升级过程不会更改已有冻结选择。本次升级前已有五个应用被用户停用，词典保持默认启用；升级后分别显示为已优化和未优化。

通过实际 UI 切换掌阅 AI 完成验证：关闭优化后，其启动入口可正常解析；重新开启优化后，系统包状态为 `DISABLED_USER`（3），入口解析和显式 Activity 启动均被阻止。测试后全部六个应用的实际状态、原始恢复备份与 Doze 开机配置均与测试前一致。设备最终停留在阅桌面。

证据位于 `diagnostics/2026-11-01-app-optimization/verification.json`，界面预览位于 `output/app-optimization-preview.png`。

## 桌面锁屏按钮

桌面底部空白区域新增居中的“锁屏”按钮，沿用现有黑白描边样式。当前设备按钮边界为 `[416,1081][656,1177]`，水平中心为屏幕中心 `x=536`；剩余空白变化时由布局自动居中，内容较多时仍可滚动到按钮。

按钮点击后短暂连接控制组件，后台执行固定的休眠键操作，完成即解除绑定。新增 Binder 方法沿用实际调用 UID 与桌面签名核验，不接受任意命令，也不写入省电配置。点击处理中禁用按钮，连接失败、超时或组件更新时提供提示并允许重试。

两个 APK 已通过构建、签名校验并更新到阅读器。锁屏专项实机测试为 PASS：点击进入掌阅原生锁屏画面，`PowerManager.isInteractive()` 返回 false；重复锁屏保持非交互状态，不会再次唤醒；测试结束恢复原屏幕状态。该固件在锁屏画面报告 `Dozing`，不将其误判为失败，也不据此宣称内核已经完全休眠。

实际 UI 验证通过：点击锁屏后控制服务绑定释放，唤醒后自动回到阅桌面，按钮恢复可用。独立 UID 调用新增锁屏接口被拒绝。原有省电偏好文件与更新前逐字节一致；测试 APK 已卸载，设备最终停留在阅桌面。

证据位于 `diagnostics/2026-11-01-screen-lock/`，包括 `lock-test.txt`、`security-probe.txt`、`ui-verification.json`、锁屏与桌面截图。最新桌面预览为 `output/launcher-preview.png`。
